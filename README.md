# CYAN Win2HDD — Downloads

Public installers and update packages for CYAN Win2HDD, a Vietnamese Windows 10/11 x64 UEFI deployment application.

Application source code is maintained separately in a private repository. This repository is for binary distribution only.

The first version is experimental and has not yet completed real Windows installation testing in a virtual machine. There is no stable release yet. Draft/test artifacts must not be treated as production-ready disk installation software.

The app uses Velopack updates. Published releases will include Setup.exe, package files and `releases.win.json`. Windows ISO files are obtained separately from Microsoft; they are not redistributed here.
